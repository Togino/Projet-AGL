# Remise du projet

## Elements importants a montrer

1. Connexion par role.
2. Espace gestionnaire :
   - classes,
   - semestres,
   - modules,
   - affectations,
   - notes,
   - reclamations.
3. Espace enseignant :
   - classes affectees,
   - saisie des notes par module du semestre.
4. Espace etudiant :
   - moyenne semestrielle,
   - notes detaillees,
   - emploi du temps,
   - reclamations.
